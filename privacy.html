1. 対象

このポリシーは、YouTubeチャンネル「Buggy Sleep」の運営者が自分で使う個人用プログラム「入眠ライブ」(以下「本アプリ」)に適用されます。本アプリは運営者以外の方の利用を想定していません。

2. 利用する情報

本アプリは、Google の OAuth 認証で運営者が許可した範囲で、運営者自身の YouTube アカウントについて次の情報にアクセスします。

  • チャンネルの ID と名前
  • ライブ配信の枠とストリームの情報(タイトル、説明文、公開設定、状態、予定時刻)
  • 配信枠のサムネイル(本アプリが作成した画像を設定します)

3. 利用の目的

上記の情報は、運営者自身のチャンネルでライブ配信の枠を作成・設定し、配信を開始・監視・終了するためだけに使います。広告、分析目的での販売、他のサービスへの提供には使いません。

4. 保存と共有

  • 認証情報(アクセストークンとリフレッシュトークン)は、運営者の PC の中にだけ保存します。外部のサーバーには保存しません。
  • 情報は Google の API(YouTube API サービス)との通信にだけ使い、第三者と共有・販売・譲渡しません。
  • 本アプリが Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

5. 削除とアクセスの取り消し

運営者は、PC に保存した認証情報を削除するか、Google アカウントの「サードパーティのアクセス」から本アプリのアクセスをいつでも取り消せます。

6. YouTube と Google のポリシー

本アプリは YouTube API サービスを使用しています。YouTube 利用規約と Google プライバシー ポリシーも適用されます。

7. 連絡先

連絡先: YouTubeチャンネル「Buggy Sleep」の運営者まで

Privacy Policy (English)

1. Scope

This policy applies to "入眠ライブ" (Sleep Music Live, "the App"), a personal program used only by the operator of the YouTube channel "Buggy Sleep". The App is not intended for use by anyone else.

2. Information accessed

Within the permissions the operator grants through Google OAuth, the App accesses the following information about the operator's own YouTube account:

  • Channel ID and name
  • Live broadcast and stream information (title, description, privacy status, lifecycle status, scheduled time)
  • Broadcast thumbnails (the App uploads an image it generates)

3. How the information is used

The information is used only to create and configure live broadcasts on the operator's own channel and to start, monitor and end them. It is not used for advertising, sold, or provided to other services.

4. Storage and sharing

  • Credentials (access and refresh tokens) are stored only on the operator's own PC, not on any external server.
  • The information is used only to communicate with Google APIs (YouTube API Services) and is not shared with, sold to, or transferred to third parties.
  • The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Deletion and revoking access

The operator can delete the credentials stored on the PC, or revoke the App's access at any time from Google Account › Third-party access.

6. YouTube and Google policies

The App uses YouTube API Services. The YouTube Terms of Service and the Google Privacy Policy also apply.
