「入眠ライブ」は、YouTubeチャンネル「Buggy Sleep」の運営者が、自分のチャンネルで毎晩行う入眠音楽ライブ配信(「ことばのない本棚」)を、自分のPCから自動で準備・開始・終了するための個人用のプログラムです。一般の方が使うアプリではありません。

このプログラムは YouTube API サービスを使い、運営者自身のチャンネルについてだけ、配信枠の作成・ストリームへの紐づけ・サムネイルの設定・配信の開始と終了を行います。

"入眠ライブ" (Sleep Music Live) is a personal program used by the operator of the YouTube channel "Buggy Sleep" to automatically prepare, start and end the nightly sleep-music live stream ("Shelves Without Words") on the operator's own channel, from the operator's own PC. It is not an app for the general public.

The program uses YouTube API Services only for the operator's own channel: creating live broadcasts, binding them to a stream, setting thumbnails, and starting and ending broadcasts.
